## Why

The English tour `Granada and the New World` needs its public imagery to match the provided `1492 New World Order` tour identity artwork. Using the approved image improves visitor recognition and makes the English tour page/catalog presentation more specific than a generic Granada placeholder.

## What Changes

- Add the provided `1492 New World Order` artwork as a public tour image asset in a web-optimized format suitable for the static site.
- Update only the English `Granada and the New World` tour entry to use that image in its `image` metadata.
- Ensure the updated image appears anywhere the existing shared tour catalog and detail page patterns render that English tour.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `static-tourism-site`: The English `Granada and the New World` tour must display the provided approved `1492 New World Order` artwork as its public tour image.

## Impact

- Affected content: the English tour content entry for `Granada and the New World`.
- Affected assets: one new public image asset derived from the provided artwork.
- Affected UI: existing catalog cards and tour detail pages that render the tour's `image` field.
- No API, dependency, routing, booking, payment, or backend changes.
