## Why

The site already has a solid technical SEO foundation, but it can compete better for high-intent Granada tourism searches by expanding localized commercial landing pages, enriching truthful structured data, improving multilingual discovery signals, and strengthening editorial topic clusters. This change turns SEO from basic page metadata into a broader acquisition architecture for Spanish and English visitors.

## What Changes

- Add localized SEO landing pages for high-intent Granada tourism queries beyond the current private-tours landing page.
- Improve metadata signals with richer Open Graph/Twitter/article tags, localized alternates, and image metadata where available.
- Improve sitemap multilingual discovery by exposing Spanish/English alternate relationships for equivalent localized URLs.
- Enrich JSON-LD using truthful tourism/local-business/service/list data without inventing addresses, ratings, physical locations, or unapproved channels.
- Expand visible tour FAQs and FAQ structured data across all published tour detail pages.
- Strengthen internal linking between Home, commercial landing pages, tours, tailor-made content, contact, and editorial articles.
- Add editorial topic-cluster support for useful Granada search intents in Spanish and English.
- Preserve the external-only WhatsApp/email reservation model and static GitHub Pages-compatible output.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `static-tourism-site`: Add localized SEO landing pages, richer page metadata, multilingual sitemap alternates, expanded tour FAQs, and stronger internal discovery links.
- `local-seo-presence`: Enrich local/tourism structured data and make structured data more connected across business, services, listings, pages, and contact channels without inventing unsupported facts.
- `editorial-blog`: Expand editorial topic clusters and linking so blog content targets useful Granada visitor search intents and connects readers to relevant commercial/tour pages.

## Impact

- Affected routes: localized Home, commercial landing pages, tour detail pages, blog listing/detail pages, contact, tailor-made pages, sitemap, and robots-adjacent discoverability metadata.
- Affected content: localized SEO landing copy, tour FAQ content, editorial article metadata and possible new article entries.
- Affected code: SEO helpers, page metadata generation, JSON-LD generation, sitemap generation, content schemas, internal linking components, and route generation.
- Dependencies: no new backend or runtime service required; implementation should remain static and GitHub Pages-compatible.
