## Why

The new day-trip pages currently reuse generic Granada imagery, but the Malaga and Cordoba origins now have approved origin-specific images. Updating them will make each private excursion easier to recognize and more consistent with the departure city being marketed.

## What Changes

- Use the provided Malaga panorama image for both Spanish and English Malaga/Costa del Sol to Granada day-trip pages and cards.
- Use the provided Cordoba Mosque-Cathedral interior image for both Spanish and English Cordoba to Granada day-trip pages and cards.
- Add localized alt text for both images.
- Keep the existing day-trip page design, layout, copy, URLs, pricing, CTAs, and reservation behavior unchanged.
- Preserve SEO/social metadata by registering the new image dimensions where needed.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `granada-day-trips`: Day-trip pages SHALL use origin-specific images for Malaga/Costa del Sol and Cordoba excursions in both locales.

## Impact

- Affected app areas: public image assets, localized day-trip tour Markdown entries, image alt text, and SEO image dimension metadata.
- No route, booking, pricing, component layout, or dependency changes are expected.
