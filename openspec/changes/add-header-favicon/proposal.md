## Why

The site header currently relies on text-only branding, which misses an opportunity to reinforce Elyara's identity at first glance. Adding the existing favicon beside the title improves brand recognition while preserving the current simple navigation.

## What Changes

- Display the site's favicon as a small brand mark in the header, positioned to the left of the `Elyara Tours Granada` title.
- Keep the header layout stable across desktop and mobile widths, with the favicon and title aligned as one brand link/group.
- Preserve the existing title text, navigation behavior, visual tone, and accessibility expectations.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `static-tourism-site`: Update the public tourism website presentation requirements so the header brand includes the favicon to the left of the site title.

## Impact

- Affects the shared public header/navigation component or layout used by localized pages.
- Uses the existing favicon asset; no new dependencies, APIs, reservation behavior, routing changes, or content model changes are expected.
