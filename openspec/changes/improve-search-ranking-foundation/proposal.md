## Why

Elyara already has a solid technical SEO base, but ranking for competitive Granada tour searches requires stronger crawl readiness, trust signals, long-tail commercial pages, and connected editorial content. This change improves the site's search ranking foundation without promising a guaranteed first-page result, which depends on competition, authority, reviews, links, and time.

## What Changes

- Add support for publishing Google Search Console verification metadata when an approved verification token is provided.
- Add localized authority content about Elyara and the guide/business, using only approved facts and no invented credentials.
- Expand localized SEO landing coverage for high-intent long-tail searches such as private guide/tour Granada, official guide where credentials are approved, Cathedral/Royal Chapel guided visit, Albaicin and Sacromonte, family tours, and day trips from Malaga/Cordoba.
- Deepen existing SEO landing pages so they are useful visitor pages rather than thin keyword pages.
- Add a connected editorial content plan that links practical Granada articles to matching tours and landing pages.
- Preserve truthful structured data: no fake ratings, addresses, review counts, official-guide claims, or business facts that are not approved and visible.
- Keep the site static, bilingual, GitHub Pages-compatible, and reservation-focused through WhatsApp/email.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `static-tourism-site`: Adds crawl verification support, localized authority pages, and broader high-intent landing coverage.
- `local-seo-presence`: Strengthens rules for search verification, authority signals, and truthful structured data around ranking improvements.
- `editorial-blog`: Adds requirements for SEO editorial topic expansion connected to commercial pages and tours.

## Impact

- Affected pages: localized home metadata, new localized About/Sobre Elyara pages, SEO landing pages, blog articles, sitemap, internal links, and structured data helpers.
- Affected content: new or expanded localized Markdown entries for SEO landings and blog posts.
- Affected deployment operations: Search Console verification requires an approved token or repository variable before the meta tag can be emitted.
- No internal booking, payment, account system, external SEO API dependency, or guaranteed ranking claim is introduced.
